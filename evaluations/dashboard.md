# Stop Slop: Dashboard Evaluation

- [ ] The screen prioritises frequent or important user tasks.
- [ ] Important status, exceptions, and actions are easy to find.
- [ ] Information order follows workflow relevance, not symmetry.
- [ ] Dense data uses a structure suited to scanning and comparison.
- [ ] Every KPI or chart answers a real question.
- [ ] Data is real or clearly marked as sample/demo data.
- [ ] Units, time ranges, labels, and filters are clear.
- [ ] Empty, loading, stale, partial, and error states are handled.
- [ ] Not every data point is wrapped in a card.
- [ ] Filters and controls are useful and functional.
- [ ] No decorative KPI strips, redundant panels, or filler graphs.
- [ ] Tables and forms remain readable and keyboard accessible.
- [ ] Destructive actions are clearly distinguished and confirmed.
- [ ] Narrow-screen behaviour is intentional.
