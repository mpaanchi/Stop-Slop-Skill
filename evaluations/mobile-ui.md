# Stop Slop: Mobile UI Evaluation

- [ ] Layout is reorganised for the viewport, not merely compressed.
- [ ] Important content and primary action remain easy to find.
- [ ] Columns collapse in a logical order.
- [ ] Labels, values, tables, and forms do not clip or overlap.
- [ ] No unintended horizontal overflow.
- [ ] Touch targets are practical and not crowded.
- [ ] Navigation, menus, and dialogs remain understandable and reachable.
- [ ] Hover-only behaviour has a touch alternative.
- [ ] Forms work with the on-screen keyboard.
- [ ] Loading, empty, success, and error states fit narrow screens.
- [ ] Sticky controls do not cover content.
- [ ] Decorative headings do not consume the screen unnecessarily.
- [ ] Repeated containers do not make the page feel cramped.
- [ ] Animation does not slow scrolling or block interaction.
